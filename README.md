# dsh-tui

Full-screen, hotkey-first OpenTUI profile for DeepSeek Harness.

Current slices: in-process Harness client bridge, reversible TUI extension
contracts, zen shell, workspace/session workflows, and streaming conversation
with a multiline mouse-accessible composer.

See [`docs/profile.md`](docs/profile.md) for installation, runtime requirements,
and default controls.
